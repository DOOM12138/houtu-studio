# 厚涂小站

精修整个人物的个人本机网站，支持二次元厚涂、COS 质感厚涂、保留原画风与自然摄影精修。使用 **ChatGPT 账号的官方 Codex 登录**，不要求 OpenAI API Key。

## 源码、目录与版本管理

公开源码：[DOOM12138/houtu-studio](https://github.com/DOOM12138/houtu-studio)。此电脑主项目目录为 **F:/厚涂小站**；在 Cindy 中打开这个项目，或双击「开发终端.cmd」继续开发。临时文件与缓存留在项目盘。

- [前后端结构](ARCHITECTURE.md)与目录内的 README 说明各模块入口。
- [AGENTS.md](AGENTS.md)（兼容入口 [agent.md](agent.md)）保存后续代理的工作约定。
- [Git 更新与回退](GIT_WORKFLOW.md)说明分支、提交、标签及版本恢复；当前基线为 1.7.0。

源码不携带私人照片、作品、登录资料、依赖或 ZIP。开发使用 Node.js 25，在项目终端执行 npm ci、npm start；免安装运行请使用完整便携包，见 [DEPLOY.md](DEPLOY.md)。

## 模型选择（1.9）

人物精修、特效合成和调色页均有「AI 主模型」下拉框。登录本站的 ChatGPT 后点击「刷新列表」，读取当前官方客户端返回、支持图片输入的可选模型；不写死型号，不需要 API Key。未登录时显示登录提示。

- 所选主模型用于读图、审美分析、反推提示词、人物检查及发起图片编辑，真实传入客户端的 thread/start 和 turn/start 请求。它不等同于底层图片模型；订阅通道的内置绘图引擎由服务提供，不能在这里任意切换 Images API 或其他平台的绘图引擎。见[官方客户端模型接口](https://learn.chatgpt.com/docs/app-server#list-models-modellist)与[内置图片生成说明](https://learn.chatgpt.com/docs/image-generation)。
- 新任务可选择跟随客户端默认；服务返回的实际模型会另行记录。任务、模板、审美方案、人物检查及创作工作流保存模型选择，默认任务取得实际模型后也会在后续重试中沿用。旧记录未保存过实际模型时继续使用客户端默认，不推测此前用的型号。
- 改变创作模型会使相关分析／反推／出图步骤待更新，缓存按模型隔离；相同模型、输入和设置下的原始出图仍可单独重合成，不重付生成额度。已有图和历史尝试保留。人物检查换模型后另建检查记录，原来的建议保留。
- 模型列表不可用或旧型号失效时保留原选择并提示重选，不偷偷换型号。刷新和切换下拉框不调用图片生成。列表表示客户端可选项，具体读图、图片工具和账号额度仍由服务校验，失败会记录在对应步骤。

本机安装的客户端已验证模型列表协议可读；模型参数、恢复、缓存和三个页面用隔离适配器完成验证。未代替用户登录或逐个消耗真实模型额度试图出图。

## 非厚涂与 1–10 级厚涂（1.8）

修图风格分为两组：

- 非厚涂：保留原画风，或自然摄影精修。保留照片、插画原有表现，摄影模式适合真人与 COS 照片；不新增厚涂笔触或色块。
- 厚涂：二次元厚涂、COS 质感厚涂，均可选择 **1–10 级**。默认 2 级，1 级最轻，5 级适中，10 级在允许修改的区域充分厚涂化。每一级有不同的画风指令。

「精修力度」的轻柔／适中／细致控制细节修整，「厚涂程度」控制笔触与色块表现，两项独立。非厚涂模式隐藏滑块并忽略保存的厚涂等级；完整自定义提示词模式继续使用你写的完整指令。人物二次精修默认保留当前画风，也可明确选择厚涂及程度。

等级会保存到任务、工作流输入和提示词模板，可在历史恢复、继续精修、模板导入导出及新电脑部署时复用。旧任务和旧模板未记录等级时，轻柔／适中／浓厚分别按 2／5／8 级兼容；原作品保留。眼睛、发丝和妆容工具改用中性名称，非厚涂模式下不会附加这些工具的厚涂转换指令。

程度控制模型的画风表现，实际效果随原图和模型变化；等级增大仍需保留人物身份、姿态、服装设计、构图和未选择区域。自动化测试验证设置与指令传递，真实图片效果仍由用户登录后检查。

## 人物细化与二次精修（1.7）

人物精修页新增「人物二次精修」工具，默认自然风格、保守细化。它是自研的类似人像后期流程，调用本站ChatGPT图片能力，并非像素蛋糕的专有模型或原版效果复刻。

- 五官、眼睛、皮肤、发丝、手部、服装、饰品和人物光影可各设0–3级。另有保守／质感／五官发丝／手部服装起点、质感保留偏好和五官锁定。等级转为编辑指令，实际细节与身份保持需实图检查，不是可测量的商业磨皮滤镜数值。
- 可先点击「AI检查这一版人物」，取得逐部位观察和细化建议，确认后采用，不自动生成图片。不可见部位关闭，避免凭空补画。输入和建议保存为独立工作流；恢复历史版本可复用已完成检查。改换输入后检查与蒙版会清空，针对新成品重新分析。
- 默认人物蒙版保护背景。用本机模型重新识别**本轮实际成品**，或上传对应灰度PNG；自备蒙版保留原分辨率。黑区保留本轮输入RGBA像素，白区允许修改，灰区按权重混合。自动分割不等同精细抠图，应检查发丝／饰品边缘，必要时修正蒙版或用矩形选区。
- 矩形和人物蒙版同时使用时，先将局部裁片合回完整图，再按人物蒙版混合，保护矩形外内容及蒙版黑区。原图、蒙版、参数和原始AI出图保存；失败后只重合成不需要重新生成。
- 创作台合成结果、调色页已导出的成品和工作流成品均可进入二次精修，按本机产物ID交接，不重新上传给本站、不重跑合成或调色。原始人物与人设参考可沿来源链继承，仅用来保持身份，不照搬旧背景。
- 「细化这一版人物」把成品作为下一轮输入，每轮另建版本。版本列表可从旧版**成品**开分支；「退回本轮输入」恢复本轮开始前的确切图片，原成品不删除。查看历史任务则恢复那一轮的输入、参数、蒙版与检查记录。

画面检查和AI精修分别使用账号额度；自动分割、历史查看、版本回退和本机蒙版合成不调用云端模型。界面与流程采用隔离适配器验证，真实效果仍需用户登录后用实际图片确认。

## 多图分析、自动找参考与反推提示词（1.6）

在「特效与合成」上传人物原图、可选人设图和背景／合成素材，再添加约5张风格参考。风格参考独立于人设和背景，最多5张；可从本机多选，也可在小红书搜索列表勾选多篇笔记加入队列，支持排序、移除和跨刷新恢复。

新工作流默认开启「自动分析人物与背景」及「自动找约5张参考」：

1. 使用ChatGPT多图视觉能力读取人物、人设、背景和已上传参考，分析形象、构图、光影、色彩与空间，并产生中英文检索主题。
2. 没有手动提供足够参考时，从独立小红书窗口或公开图库有界采集候选；最多8张候选，保留来源。小红书按最多8篇可见笔记、每篇1张大图截图处理，不声称已自动读取轮播全部图片。登录或验证会暂停；已有图片保留，重试不重新抓取已取得的同一笔记。
3. 再读取人物、背景和所有候选，逐图输出观察、适配度及理由，选出约5张，并同时反推小特效、小合成、大合成三套正向／避免提示词。手动上传与明确勾选的参考优先；手动多选可指定1至5张，目标张数主要控制自动选择。
4. 小特效和本机小合成还会得到粒子类型、强度、位置、比例、旋转、透明度与混合方式等结构化建议；这些参数实际进入合成引擎，不只是展示文字。关闭「采用AI建议」可使用手动参数。预览与最终输出共享有效参数计算。
5. 反推提示词可查看、修改、复制、导出为JSON，并明确保存后用于当前任务。编辑正文会自动保留图片角色映射，避免图号错配；手改文字、重新导出及切换建议参数不重新调用前面的视觉分析。改变图片、创作要求、目标选择等会使相关步骤待更新。

分析最多接收16张图；实际人物＋4张人设＋背景＋8张候选最多14张。最终出图只附筛选后的最多5张风格参考，连同人物／人设／背景最多11张，不静默截断。每张参考的角色、来源、分析、选择与实际使用都写入工作流。

AI分析会发送原图、背景、已选参考和自动取得的候选图给你登录的ChatGPT，并消耗账号额度。通常包括检索规划和反推两次分析；AI出图另计。关闭自动分析／自动找参考即可纯手动本机创作。没有可用分析结果时会在该步骤报错，不以规则模板冒充AI反推成功。此前的老工作流会保留成品并默认不启用新分析，避免升级后自动重放调用。

实际人物识别、审美和提示词质量仍需使用用户账号与真实图片确认；测试采用隔离视觉适配器验证了完整传图、选择、参数落地、缓存及断点续跑，并未冒充完成用户实图分析。

## 特效、合成与人设创作（1.5）

顶部「特效与合成」进入 `/creative/`，支持小特效、透明素材叠加、人物换背景、大场景合成、3D手办效果图、3D渲染质感图和自有标记清理。

- 粒子、光斑、雪、雨、花瓣、薄雾、光晕在本机用确定性引擎生成，可设置强度与种子；小合成支持位置、比例、旋转、不透明度和混合模式。换背景与特效避开人物使用本机分割蒙版，也可上传自己的灰度蒙版。原图透明度与蒙版相乘。
- 最多4张人设图，加一张素材和一张风格参考；角色说明与全部图像一起进入AI出图指令。AI大合成、3D质感图片和自有标记清理需要本站独立的ChatGPT登录与额度，尚未使用用户真实账号完成效果验收；不会用本机滤镜冒充AI出图。
- 半自动每完成一个阶段就暂停，确认素材、布局后再继续；全自动从素材执行到交付。每步的输入、配置、产物和错误进入工作流。AI原始出图先保存，再进行局部合成；断点恢复优先复用匹配的原始图。只有明确点击“重新调用AI出图”才强制生成新图。
- 自动素材检索来自 Wikimedia，过滤到明确允许相应用途的 CC0／公有领域／CC BY／CC BY-SA，并保存来源、作者和许可。图片可能仍需署名和同方式共享，网站不替使用者重新许可第三方图片。网络或检索失败就停在素材步骤，可改关键词或上传素材后继续，不伪造素材。
- 可选择“按原图／人设规划关键词”：当自动找素材且没有手动关键词时调用ChatGPT读取原图及首张人设参考，再搜索；这会使用账号额度，成功的关键词规划会保存，下载失败后重试可复用。
- 水印／标记清理用于自有或已获授权的图片，需要确认并指定局部矩形，选区外保留标准化原图像素。网上素材优先使用无水印授权原图；平台截图保留水印，仅作风格参考，不自动去除第三方版权水印。

**2D转3D目前输出PNG质感图，不输出GLB／OBJ真实网格。** 未将图片叫作可编辑3D模型，未内置TripoSR等大型真实网格重建环境。

## 小红书登录与参考

在创作页打开“小红书独立登录与参考”，点击打开窗口，在官网手动扫码或完成验证码。网站使用自己的Edge／Chrome profile，**不是小红书官方OAuth内容授权接口**，不复制Cindy、日常浏览器的Cookie或密码。关闭窗口后登录资料留在本机 `data/platform-browser`，不进入便携发布包。

可以在这个窗口搜索、手动打开笔记后取当前可见大图截图，或勾选运行时自动搜索并选取一篇当前可见笔记作为风格参考；都会保留水印和来源。页面有登录／验证提示时明确报错，等待你手动完成，不绕过限制。登录不代表无限访问、可读取全部笔记或取得图片合成授权。自动选择只读取可见笔记，不批量抓取、发帖、关注或操作消息。

目标电脑需要已安装Edge或Chrome才能使用独立平台窗口；普通调色与本机合成不额外下载浏览器。小红书实际扫码和账号访问需用户亲自完成；本轮测试验证了窗口适配接口与权限隔离，没有冒充完成账号登录。

## 工作流管理（1.4）

打开顶部「工作流管理」，每一步可展开查看状态、输入依赖、参数、图片/蒙版产物、历次尝试及失败原因。检查点保存在本机 `data/workflows`，刷新网页或重启网站后仍能继续。

- 人物精修按「原图与提示词 → 裁片与编辑输入 → AI原始出图 → 合成保存」记录。合成失败只需点击「只重新合成」，直接使用已保存的原始出图和完整原图，不再调用模型。重新生成会明确提示可能消耗账号额度。旧结果和每次尝试保留。
- 调色按「原图、参考图、审美方案、人物与手绘蒙版、全局与局部调色、成品导出」记录，参考和审美方案可选。原尺寸图片、浮点分割结果、全部画笔增减笔触及参数均可恢复。停止操作后约1.6秒自动保存，也可点击「保存检查点」；以界面显示保存成功为准。
- 从选定步骤继续，只将其后续依赖标为待更新；独立、已完成的步骤不重做。旧产物仍能在历史尝试里查看，不会冒充本次新结果。调色的「从这一步继续」恢复编辑器及输入，点击对应执行按钮才运行；不会自动消耗AI额度。
- 原尺寸成品保存在导出步骤，可随时重新下载。只重新导出会复用已保存调色和蒙版，不重新分析、不重新分割、不重新调用AI。
- 服务重启后，未完成步骤标为中断，不偷偷重放收费调用。重复点击和过期结果由执行编号与版本检查拦截。精修成品进入调色时创建关联工作流，可返回前序精修记录。

1.4起的新任务才有完整工作流记录；旧精修历史仍保留，但旧版未保存的原始出图和笔触不能凭空补回。便携软件包不会带走工作流、照片、成品或账号；打包预设也不包含项目笔触。

## 调色与蒙版（1.3）

顶部「调色与蒙版」打开 `/color/`，真人和二次元插画都可使用：

- 本地确定性调色：线性光曝光、相对白平衡及取样校正、对比度、高光/阴影/黑白色阶、自然饱和度、8 色 HSL、RGB/单通道五点曲线、三段色彩分级。
- 全局和最多12层蒙版独立调色。自动人物、背景、头发、皮肤、面部皮肤、服装及饰品蒙版；画笔、亮度范围、颜色范围、线性/径向渐变；画笔增减、柔边、基础蒙版反转、图层开关及透明度、撤销重做。
- 内置 Google MediaPipe 多类人物分割小模型（16.4 MB），WASM 和权重随包携带，离线运行。它不是本项目自行训练的蒸馏模型；主要针对真人，动漫与复杂边缘需检查和手绘修正。模型卡、权重校验及 Apache-2.0 许可在 `models/`。
- 上传参考图，或读取小红书、Unsplash、Pexels、Wikimedia 公开链接；匹配明暗、冷暖与饱和度。按主题自动检索 Wikimedia 图库并显示来源/许可。登录限制页面或无公开封面时提示上传图片，不绕过登录。这是统计色彩匹配，不是语义风格迁移。
- 可选「ChatGPT 审美分析」：独立官方登录后，将预览和当前参考图发送给 ChatGPT，返回整体审美说明、全局/人物局部参数与参考检索主题；先查看说明，再点击应用。需要网络和账号额度，尚未使用用户账号完成实图效果验收。
- 保存、导入、分享 JSON 调色预设；包含参数与可重算蒙版规则，不含照片、自动蒙版像素和手绘笔触。导入追加不覆盖。可导出全局17³ `.cube` LUT，不含局部蒙版，不是 Lightroom XMP。
- 预览和原尺寸 PNG 导出共用同一引擎。支持30 MB / 24 MP的 PNG/JPG/WebP，处理 sRGB 8位位图；不是 RAW/HDR 显影器，参数不与 Lightroom 等价。原图不会覆盖；工作流检查点保存成功后，笔触和参数可跨刷新恢复。

人物精修完成后也可点击「进入调色」，本机交接图片不调用 AI。

## 前后端分离

`frontend/` 为独立静态调色前端与 Web Worker 引擎；`backend/` 负责预设和公开参考，`server.mjs` 提供 JSON API、原精修服务及默认本机托管。默认一键启动仍是同一地址。

开发时 `npm start` 启动后端4317，另一个终端执行 `npm run start:frontend` 启动独立前端4319。可设置环境变量 `BACKEND_URL=http://127.0.0.1:4317` 指定后端；用严格本机同源代理连接 API、模型和原精修页面，不放开任意 CORS。两者面向个人本机使用，不是公网多用户架构。

## 启动

双击 `启动网站.cmd`，会自动启动后台服务并打开浏览器。默认地址为 <http://127.0.0.1:4317>，占用时自动选用其他本机端口。重复启动会打开本站现有实例；双击 `停止网站.cmd` 停止服务。

1. 点击「使用 ChatGPT 登录」，在 `auth.openai.com` 官方网页中完成登录，返回网站。
2. 上传 PNG、JPG 或 WebP 图片（不超过 12 MB）。
3. 左侧选择功能，右侧选择画风与精修程度，点击「开始精修」。手机上点开「精修功能」选择工具。
4. 需要只修一处时，点击「画局部选区」，在放大的原图上拖动矩形；也可展开比例输入框，用键盘设置选区。
5. 完成后可并排查看、滑动对比、下载，或点击「继续精修」把当前结果作为下一版原图。历史版本仍保留。

默认「整个人物精修＋二次元厚涂 2/10＋轻柔精修」，保留人物身份、姿态和完整取景。程度选择会改变模型指令，不是固定数值的图像算法；实际效果需要根据原图调整。

## 人物精修工具

- 整个人物精修：可勾选五官、眼睛、发丝、皮肤、手部肢体、服装、饰品材质及全身光影。
- 面部精修、厚涂眼睛、厚涂发丝、厚涂妆感、肤色统一、手部与肢体。
- 服装整理、材质精修、饰品与道具、发丝飘动。
- 人物光影、背景清理、二次元厚涂、COS 质感厚涂、自定义修图。

共 17 个工具，使用同一 ChatGPT 图片能力与不同的自研编辑指令。完整指令可在界面展开查看和复制；源文件为 `public/catalog.js` 与 `lib/painting.mjs`。

未画选区时，由模型按功能识别应编辑的部位；这时不能保证其他区域像素完全不变。需要严格保留其他画面时，请使用局部选区。

历史恢复和继续精修按本机作品 ID 引用已保存图片，避免将标准化后较大的 PNG 再次套用外部上传的 12 MB 限制，也不需要浏览器重复上传这些文件。生成时所需图片仍会发送给 OpenAI。

局部精修先标准化原图 EXIF 方向，再外扩选区裁片作为编辑目标，同时附完整原图供身份与光线参考。生成结果按裁片尺寸映射，仅合成回所选矩形，边缘做少量羽化。下载与历史保存的是完整合成图，选区外保留标准化原图的像素；原始尺寸不足 64×64 的选区会被拒绝。

本版根据耀 AI 和幻象 AI 的公开功能资料自研，没有取得或复制它们的私有源码、模型或官方提示词，不能视作原产品效果复刻。调研依据见 [SOURCES.md](SOURCES.md)。

## 写提示词与模板

页面上方的提示词编辑器支持 6000 字：

- “补充描述”模式：结合所选功能、画风、程度和人物部位，自动组合完整指令。
- “完整自定义”模式：使用你写的完整指令，不自动追加工具和画风描述；原图和局部裁片的传递说明仍保留。
- 保存为新模板或明确更新所选模板；模板包含文本及修图设置，不保存图片和选区。
- 导出当前 TXT，或导出整个 JSON 提示词库；可导入 JSON / TXT。导入追加新内容，不覆盖已有模板。
- 模板保存在本机 `data/prompts.json`，不需要登录即可编辑保存。文字输入和模板管理不会调用 AI，也不消耗生成额度。

## 打包到其他电脑

页面下方点击“打包 Windows 便携版”，完成后下载 ZIP。也可运行 `npm run package:portable`。

包内自带 Node.js、官方 Codex 客户端和图片处理依赖。目标电脑是 Windows 10/11 x64，不需要安装 Node、npm、Python 或 Cindy；解压后双击 `一键部署.cmd`，或直接运行 `启动网站.cmd`。新电脑需要联网并单独完成 ChatGPT 官方登录。

打包按白名单生成，不复制账号、照片、作品、日志和备份。包含模板选项会加入提示词和调色参数预设，不加入照片与手绘笔触。前后端、内置模型及许可证均随包携带。详细步骤见 [DEPLOY.md](DEPLOY.md)。

## 登录与费用

- 网站通过本机的官方 `@openai/codex` 客户端工作，首版锁定版本为 0.172.0。
- 使用你登录账号可用的 Codex 订阅额度。没有另行调用付费 Images API；图片生成仍会消耗订阅额度，并非无限免费。
- 支持情况受账号套餐、工作区设置、网络和 OpenAI 服务影响。登录成功不代表一定有图片额度。
- 凭据由客户端保存在 `data/codex`，与 Cindy 的登录存储隔离；本站不读取 Cindy 的凭据，也不要求粘贴任何令牌。
- 通过官方 app-server 的 JSON-RPC 协议调用 `account/login/start`、`thread/start` 和 `turn/start`，读取真实 `imageGeneration` 完成事件。未返回真实图片时明确报错，不用滤镜或占位图伪造成功。
- 此版本面向你自己在本机使用，不是让公网访客共享订阅的多用户服务。

官方资料：[账号登录](https://learn.chatgpt.com/docs/auth) · [内置图片生成及额度](https://learn.chatgpt.com/docs/image-generation)
