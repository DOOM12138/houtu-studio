# 智能调度与跑图

打开照片项目，在右侧“配方”展开“智能调度”。勾选1–5张照片，选择人物细化、净场、厚涂、衣料、瘦腹、影调或4K超分，并填写补充要求。每张照片都有独立方案，不把一张照片的人物范围复制到另一张。

“先生成方案”只识别图片、写提示词和安排步骤，不启动图片生成。“规划并连续处理”在方案应用后开始运行；每张AI步骤上限可选1–3次，整个项目仍最多两张并行，同一张内部逐步执行。执行前会显示所选照片数和最大AI步骤预算；实际调用次数以方案和工作流记录为准。

调度有两条路线：

- 本机视觉模型＋规则：使用随包MediaPipe人物分割和面部识别模型，在浏览器内运行；它不是蒸馏语言模型，不具备复杂审美推理。后端记录来自浏览器的识别信息及来源，不冒充服务端独立验证。识别不可靠时省略人物细化，并给出原因。人物与衣料可合并到一次跑图。
- ChatGPT审美规划：使用本站独立登录账号的可用模型读取本轮原图预览及每张最多5个功能参考，理解画风、光照和任务，再返回经过验证的配方。此阶段不允许模型使用图片生成、网页或代码工具。

“按电脑能力选择”会检测模型文件完整性、CPU与物理内存。轻量任务在至少4GB内存、两个CPU执行单元时优先本机；资源较少时建议ChatGPT。参考池、厚涂或复杂审美指令优先ChatGPT。至少8GB内存及四个CPU执行单元时建议两张并行，否则一张。这是资源建议，不保证任意大图的处理速度。界面会说明本轮实际使用的路线。

“ChatGPT规划模型”与“AI跑图主模型”独立选择。规划保存所选与实际返回模型，跑图沿用照片工作流的独立账号／模型规则；两种阶段的额度和回执分开记录。模型不可用时提示重选，恢复旧任务仍需对应账号。

方案可查看每一步的提示词，也可载入配方草稿后通过原编辑器修改和应用。直接“应用各张独立方案”使用上方保存的原方案；载入草稿后的修改应使用配方编辑器的“应用到所选照片”。二者都会保留旧工作流，项目历史可整组撤销。

净场需要已确认的主体保护蒙版。缺少参考、目标部位，或本机方案无法确认瘦腹范围时，自动运行会停在应用后的待确认状态；补齐输入后在“工作流”运行。模型不能添加未选择的瘦身、厚涂、调色或超分任务，也不能自行编造坐标选区。

每个规划工作流保存输入预览、参考用途、逐张方案、完整提示词、原始返回、模型与账号快照，不包含登录凭据。分析失败后“从未完成的分析继续”复用已完成照片；项目或照片版本变化后需重新规划。应用具有重复提交保护。刷新只打开保存的方案，不恢复自动跑图授权。

当前接线验收使用合成色块、实际内置模型加载和模拟ChatGPT。真实COS、人物照片与二次元插画的规划审美和最终效果仍需在本站账号中用实际素材验证。Android的主模型兼容与真实出图边界见项目内android/VALIDATION.md。
