# 编辑历史与撤销

- Ctrl+Z：撤销。Mac可用Command+Z。
- Ctrl+Shift+Z或Ctrl+Y：重做；Mac可用Command+Shift+Z。
- 正在输入文字或数字时，快捷键保留输入框自身的撤销；点击画布或历史按钮后可撤销图片编辑。中文输入法正在组词时不拦截按键。

人物手动修图右侧“历史记录”显示笔触与已撤销的后续步骤，可点击回到某一步，或点“0·原图”。重做后像素按原笔触重新计算。新笔触会建立新分支，清除本次重做队列；此前保存的版本仍在。打开另一张图会切换历史上下文，不能把上一张人物的笔触撤销到当前图片。

调色工作台有本次编辑历史（最多35个撤销状态）和已保存检查点。可恢复曝光、曲线、HSL、影调、蒙版与笔触参数；打开已保存版本前先保存当前编辑。历史检查点必须属于同一原图，加载对应的蒙版检查点和分割数据。恢复保存版本后的继续编辑／导出会保存为新的检查点，旧检查点保留。

照片工作台顶部有“撤销／重做”，右侧增加“历史”。配方草稿保留最多100个状态，不会自动应用或启动AI。已保存的项目默认配方、批量应用、同步、单张版本恢复记录在服务器的项目历史中（最多100次操作）；批量应用／同步算一次操作，撤销时整组选中照片回到各自先前工作流。每张照片的全部流程版本仍单独保留，可直接恢复。

版本恢复只修改当前工作流指向，不删除原图、图片产物或其他分支；保留该版本自身的模型、账号、主体保护和参考图。修图运行时不能切换版本；多个页面操作冲突时需要刷新，避免覆盖新修改。项目备份恢复会重映射历史编号，新项目的撤销不会指向旧项目。

蒙版编辑器的Ctrl+Z／重做优先作用于该蒙版；最多保留20步，并按压缩快照的内存预算淘汰较早步骤。已保存蒙版随对应的流程版本保留。

AI页面区分设置历史和成品历史。修改待运行参数可以撤销；成品撤销回到本轮保存的输入，重做打开已有结果。未点击开始修图时，这些操作不会发起新的图片生成。更早的生成／合成尝试仍可在完整工作流中查看。从同一流程的失败步骤继续会校验原有账号，不会静默改用新账号额度；明确新建一轮时按当时账号另行记录。

本次未保存的草稿、笔触和撤销队列属于当前编辑会话；需要跨关闭／刷新保留时先保存版本或检查点。已保存的图片和操作历史存放在项目私有data目录，不进入公开发布包。
