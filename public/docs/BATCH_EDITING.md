# 一组照片的同步与批量处理

打开“管理与工具 → 照片项目”，进入照片工作台，创建项目并一次导入多张图片（最多200张）。桌面中央保持大图、底部显示照片条，右侧切换配方、同步、工作流和蒙版。

1. 在照片卡片勾选要处理的照片。点击某张卡片的“设为同步来源”，或选择“当前配方编辑器”。来源照片不作为自己的同步目标。
2. 在“同步到所选照片”勾选全局调色、AI精修、裁切清晰度、超分或导出设置。来源没有某类步骤时，目标的该类步骤保留。模型和账号继续沿用目标照片自身的记录。
3. 点击“预览同步范围”，查看会新建几版、可复用几步、后续需要几个AI步骤。确认同步后，原图和旧版本保留；此操作不执行AI。
4. 切换右侧“工作流”面板，点击“连续处理所选 · 全自动”。默认同时处理两张，也可选择一张以降低内存占用。每张内部按顺序处理，互不混用产物。可以让一张出错后继续其他照片。
5. 暂停会让已经开始的步骤保存完成，然后停止。已完成的检查点会在继续时复用；失败或状态未知的AI请求不自动重新提交。照片详情提供逐步产物和恢复入口。

配方编辑器里的修改需要先同步或应用；运行按钮执行各张照片已经保存的流程，允许不同照片保留不同配方。“保存项目配方”仅决定新导入照片的默认配方，“应用到所选照片”会完整替换选中照片配方并保留旧版本。

从照片详情进入“继续局部调色”，保存后点击“同步调色到项目所选照片”。此交接同步来源流程的全局调色及新增全局参数，保持来源与目标的各自素材；手绘笔触与局部蒙版不会迁移。若来源流程已换成另一版本，请从当前照片重新进入。

在配方的全局调色步骤可读取“调色与蒙版”中保存的预设，仅取全局参数；含局部图层的预设会标明“仅全局”。需要局部处理时进入该照片的调色工作台。

仅同步AI之后的调色时，会复用目标已完成的AI前缀。若改动在AI之前，预览会列出需要重做的AI步骤，只有明确运行才会请求生成。局部矩形选区属于单张照片，不能直接同步为其他照片的AI范围。

并行调度、异常恢复和像素保存的自动化测试使用隔离模拟客户端，不代表真实ChatGPT账号的同时出图能力已验收。安卓独立运行沿用原有组件限制，见android/VALIDATION.md；本版不更改模型或账号来源。
