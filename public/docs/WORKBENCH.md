# 照片工作台

入口：管理与工具 → 照片项目。使用现有厚涂小站的浅色／深色主题，按摄影修图的习惯组织；这里的像素蛋糕式布局指操作结构，图像处理与ChatGPT工作流继续使用本项目的独立实现。

## 看图与选片

桌面中央显示当前照片，底部是项目照片条，右侧是参数面板。照片条和右侧分别滚动，不必把大图挤到页面下方。点击“全部照片”进入图库，可评分、标记保留或淘汰、检查相似提示；点击缩略图返回“单张精修”。

单击照片只改变当前查看的照片，复选框决定批量目标。Ctrl／Command点击可切换多选，Shift点击可连续选择。照片区获得焦点后，Ctrl／Command+A全选，不占用参数输入框中的文字选择快捷键。使用“上一张／下一张”检查同组照片。

图片支持成片、原图、并排和滑动对比，以及同步缩放、平移、1:1与专注看图。刚导入而未执行流程时显示的仍是原图；待执行提示不会被当作AI完成结果。

## 右侧四个面板

- 配方：选择预设、编辑有序步骤、保存默认配方、应用到选中照片或分享配方。详细参数按步骤展开。
- 同步：以当前照片、另一张照片或配方编辑器为来源，勾选同步类别，预览影响，再确认参数。同步不自动启动AI。
- 工作流：半自动下一步、全自动批处理、暂停与进度；下方查看当前照片每一步的结果、AI子流程和恢复入口。
- 蒙版：为当前照片设置主体保护和最多5张功能参考。蒙版与参考各张独立保存。

面板切换保持编辑器内容和已准备的同步预览。改变选择或参数后须重新预览同步；运行的是每张照片已经保存的流程，编辑器未应用的修改不会偷偷执行。

原图或已有成品都可以直接进入“人物手动修图”“继续局部调色”或“超分4K”。这些交接保留来源工作流，不必先调用AI。手动笔触和照片专属局部蒙版不会复制给其他照片。

## 手机和平板

手机在选定项目后折叠项目管理，需要新建或切换时展开“项目管理”。照片条在自身区域左右滚动，参数面板放在图片和照片条下方。平板使用上下布局；桌面宽屏使用固定画布和右侧独立滚动的参数区。切换明暗主题会保存到本机。

图像效果、模型能力和账号额度仍以实际任务回执为准。本版布局与同步检查不消耗真实图片生成额度，不能当作新增模型的效果验收。

布局参考：[像素蛋糕公开的精修与批量同步说明](https://wiki.pixcakeai.com/guide/9591.html)。
