# 修图Agent

## 按显卡自动选择模型

新建Agent默认“自动·按显卡配置选择”。服务器检测DXGI专用显存、NVIDIA可用显存（可取得时）、内存和CPU；共享系统内存不会计作专用显存，不把多张小显卡的显存简单相加。约8 GiB显卡／16 GiB内存可候选Qwen3-VL 4B，约12 GiB显卡／24 GiB内存可候选8B；可用资源、驱动和实际运行验证还需满足要求。门槛为本站保守策略，包含驱动保留显存余量，不是性能保证。

- 配置不足、无法确认或手机平台：纯云端AI，分析、规划、人物蒙版、AI修图、检查和需要的云端细节增强走ChatGPT；不调用本地视觉模型、ONNX分割或Real-ESRGAN。
- 配置合适：项目独立本地视觉语言模型负责读图、规划和语义检查，云端完成AI出图及最后复核。语义模型不具有文件、命令行或联网工具权限，所选节点仍由本站校验后执行。本机蒙版和专用超分可复用随包模型。
- 普通读图、精确调色、程序特效、像素回贴、插值和导出是本机非模型计算，不需要GPU模型，纯云端AI路线也会使用这些能力。

本地运行时和大权重不进入安装包。合格机器首次开始时按需从官方来源准备Ollama和锁定版本Qwen3-VL，下载约5–8 GB；缓存放项目`.cache/local-agent/`，模型和独立运行资料放`data/local-agent/`。不注册全局服务，不借用Cindy或其他应用的账号、运行时、模型目录。检查官方清单、视觉能力及实际GPU驻留后才向本地模型发送照片，CPU回退不能算作GPU Agent通过。

自动路线中本地调用、格式校验或资源条件失败，会保存原因并转云端；图片生成请求继续使用原有账本，不自动重复生成。强制“本地＋云端”不可用时等待处理。恢复／换电脑会在下一步重新检查当前机器，前面图片和回执保留。旧版流程按原路线恢复；从新一轮或新分支选择硬件路由。

云端人物蒙版单独计入图片节点预算，检查不可靠时暂停确认。云端4K是云端细节增强：原生生成尺寸与交付尺寸分别显示，必要时交付尺寸由普通插值调整，不冒充原生4K细节或本机Real-ESRGAN。独立的手动调色、蒙版、离线超分工具继续保留原能力。

照片项目右侧新增“Agent”。在“新一轮设置”勾选功能、填写要求，分别选择调度模型与跑图主模型，再开始。默认全部功能不勾选；没有勾选时只保留并导出原图。可用基础人物、COS厚涂、合成创作预设显式勾选一组功能。

## 三个挡位

- 全自动：服务端持续执行分析、找参考、规划、主体分割、所选修图／创作、检查与交付，页面关闭后仍在当前电脑／手机服务中处理。退出服务或系统终止进程会中断；重新打开后从检查点明确继续，不自动重放不明图片请求。
- 半自动：每个可查看节点完成后暂停，由你继续下一步；可查看提示词和实际图片。
- 手动：建立时只保存输入，不暗中调用模型分析、搜索或跑图。选择节点执行，或填写“手写整套方案”跳过模型分析／自动搜索，再逐个执行所选节点。

勾选项是服务端执行边界。人物／衣料／厚涂合并成一次所选人物处理，平滑瘦腹保留独立局部步骤；净场、小特效、小合成、大合成、3D质感、调色与4K分别独立。不勾选的节点不创建，模型返回额外功能会被拒绝。每张最多1–8个图片节点，预算不足先调整勾选或上限，不会自动扩容。检查后自动细化一次是独立选项，计入上限，不循环生成。

自动找图优先使用可公开访问的图库；小红书使用本应用独立平台会话。平台受限可选择公开图库备用。每张参考保存用途、来源、作者及许可；平台例图保留水印并仅作风格参考，直接合成素材需明确许可。实际不足5张会显示真实数量；允许原创生成时会记录该方式，不假装取得不存在的素材。

## 中间再次生成

每步可在画布查看结果、下载或进入精确对应的手动修图入口。展开“此步重新生成·新分支”，选择后续执行方式并填写可选新提示词。新父／子流程保留目标前已完成的图片和分析检查点，目标与后续重新执行；旧成品和旧工作流不覆盖。项目历史可Ctrl+Z整组撤回分支指向。

“继续”会找回原有图片请求与结果，不等同于再出一张。原请求结果未知时不会自动重复提交；另开一次生成需要明确确认。启动和分支使用稳定请求编号，回执丢失后找回同一次任务。只调整已经生成结果的蒙版／融合，应进入AI子工作流使用原始图重合成；主动重新生成则使用新分支。

## 模型与检查

调度模型负责读图、关键词、参考选择、逐步提示词和质量检查；跑图主模型负责现有ChatGPT内置图片能力，两者独立并保存所选／实际模型和各阶段账号。使用本站官方独立登录，不需要API Key。已完成阶段仍绑定当时账号，恢复不会悄悄换账号额度。

本机路线是公开视觉模型、图像指标与任务规则。新增固定版本MediaPipe ONNX小模型支持后台CPU／Android WASM主体分割，不要求页面保持打开；不是自行训练或蒸馏的语言模型。识别不可靠时暂停确认，不使用几何图形冒充抠图。自动找图或复杂创作在自动路线上使用ChatGPT语义规划；本机调色、程序小特效和超分仍在设备端运行。

瘦腹必须确认可见腹部及局部范围，复用原有smooth-belly guided处理与宽过渡曲线，考虑衣褶、印花、腰线和背景。检查会比较原图与实际成品的身份、光向、肤色、接缝等；分项失败或重大问题不能仅凭总评通过而自动交付。可修的轻微问题按选项最多细化一次，再检查；其余等待你确认或开新分支。手动接受记录为用户声明，不冒充模型检查通过。

## 教程方法库与验证范围

方法来源见Agent面板：乐色Lesir的公开场照暗调／修脸视频抽样画面，以及Adobe／Aaron Nace合成教程的公开字幕和示例画面。方法已写入版本化知识库、提示词和检查规则；不打包原视频、字幕、第三方练习图或付费课程，也不声称训练了基础模型权重。

本轮开发验证使用合成图片、实际本机分割推理和模拟ChatGPT；真实COS／二次元图片的生成审美仍需实际账号回执和图像对照验收。Android真实账号、ARM手机与代码模式模型的原有限制继续见android/VALIDATION.md，不把模拟器／接线测试当作实图画质通过。
