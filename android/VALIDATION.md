## Code Mode 模型组件的额外边界

本次Windows真实出图修复补齐了官方codex-code-mode-host组件。当前Android原生客户端归档仍只有app-server，尚未携带对应的Code Mode host。依赖该组件的code-mode-only主模型不能据桌面成功推定在手机可用；仍需完成V8/Bionic移植并验证。兼容模型的真实账号绘图也不在本轮无账号设备检查范围内。Android自动更新提醒、原生API握手与本机图像功能的测试结果和这项限制分别记录。
