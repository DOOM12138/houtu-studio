# 后端

项目根目录执行 npm start，默认 http://127.0.0.1:4317。server.mjs 提供 HTTP API，此目录保存工作流、调色预设、参考检索、创作合成、视觉分析、平台浏览器与人物检查模块；lib/ 保存官方 Codex、提示词和图片处理适配。

API 面向本机，写操作校验同源与 CSRF。账号、照片及所有任务产物保存在私有 data/，不进入仓库。工作流保留历次尝试；恢复优先复用输入匹配的检查点，不能自动重放收费调用。

测试使用隔离适配器，不需要账号；真实登录和图片效果需用户在目标电脑验证。结构说明见 ../ARCHITECTURE.md；项目约定见 ../AGENTS.md。
