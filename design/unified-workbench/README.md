# 单画布修图工作台 · 交互方案

修一张场照时，先把脸放大到合适的位置，调整曝光，再拿中性灰笔刷提亮眼下。换笔的那一刻，脸仍在画布的同一位置。照片、选区、笔触和撤销记录属于这张照片，工具面板只负责当前要做的事。

[交互原型](index.html) 打开后可直接在示例照片上操作。F 盘交付的「单画布修图工作台.html」内置三张示例图，可断网使用。仓库里的版本通过公开素材链接加载示例，也支持导入自己的 JPG、PNG 或 WebP。导入和编辑在浏览器本机完成。

## 打开后的第一分钟

1. **进入画布。** 正式版空项目只突出「导入照片」，旁边提供「试用示例」。打开已有项目则回到上次选中的照片。交互原型默认打开一张蓝发角色场照，可直接试修。
2. **先完成一个调整。** 初始面板只展开「调色 → 基础光线」。拖动曝光即时预览，松手只增加一条历史。原图、对比、撤销和导出一直可见。
3. **就地换工具。** 点「人物 → 中性灰 → 减淡」即可在刚才的位置落笔。返回调色可以继续动同一个曝光滑块。点击历史某一步先预览，选择「从此处继续」才建立分支。
4. **需要时交付。** 点「导出」选择格式、核对目标版本与宽高，然后生成成片。临时按住原图对比时仍导出成片，显式选中历史快照时导出所选版本。

## 菜单放在哪里

桌面以中央画布、左侧工具分类、右侧参数与底部照片条组成一个窗口。右侧一次只展开一组设置。手机使用底栏分类和画布下方可收起的参数区。照片条按需展开，编辑时只滚动参数区。

| 入口 | 下一层 | 打开后看到什么 |
| --- | --- | --- |
| 调色 | 基础光线、颜色、风格预设、局部调色 | 默认三个滑块。高级色彩再进入曲线、HSL 和颜色分级。有蒙版时，面板标题旁明确显示「调整全图」或「调整框内」。 |
| 人物 | 皮肤与光影、五官、身形与衣物 | 中性灰与高低频就地选笔。工具说明只在首次使用或需要取样、绘制保护区时出现。 |
| 图层 | 图层列表、当前图层属性 | 先选择图层，再显示文字、位置、混合或蒙版参数。画布与当前照片保持一致。 |
| AI 修图 | 按用途找任务、常用扩图与厚涂 | 先选择目的，再看范围与预计步骤。参考图、模型和提示词按需展开。预览版可按类别查找 1.35 已登记的 75 项任务，实际模型调用留在正式版。 |
| 步骤 | 编辑历史、AI 工作流 | 当前照片的操作和产物在同一个侧栏。可预览输入或旧产物，从明确失败的步骤继续。结果未知的调用保留「待核对」状态。 |
| 照片条 | 单张、多选、全部照片抽屉 | 换图、评分、筛选、批量同步在照片旁操作。同步前显示来源、目标数量和参数范围，每张照片沿用自己的蒙版。 |

「找工具」支持名称和常见说法。例如输入“灯架”可直达对应任务。搜索结果显示菜单路径，选择后原位展开。项目备份、模型登录、日志和更新放在项目菜单的「管理」里。日常编辑不需要先了解服务器、模型或工作流。

## 切工具时发生什么

**原有路径。** 1.35 的人物、调色和图层页各自维护画布。跨板块导航会调用当前编辑器的准备逻辑，必要时渲染整张 PNG、写入交接记录、切换页面，再从素材引用加载图片。无修改时已有部分复用，图片来源可追溯。成本来自把切工具和生成交付图片放到了同一条路径。[现有导航](../../public/workspace-continuation.js)

**新交互约定。** 每张照片拥有一份编辑会话。它持有原始素材引用、共用预览、图层与蒙版、操作顺序、当前版本以及画布的缩放和平移位置。切分类只更新面板、活动工具与光标。刚在编辑的输入值可以记入操作记录，切换本身不产生修图步骤。

| 用户动作 | 计算与保存的时机 |
| --- | --- |
| 拖动滑杆、绘制笔触 | 先更新预览。松手或落笔完成时合并为一条操作。正式版在后台把参数和笔触写入项目，保存失败显示「尚未写入」并保留当前会话。 |
| 打开另一个分类、找工具、展开历史 | 复用当前画布与图片，保留范围和位置。切分类不触发图片上传、全尺寸编码、模型分析或生成。 |
| 换照片、并排或滑动对比 | 照片各自保留视口与编辑状态。原图与成片使用同一坐标变换。只有选中另一份素材时，才按需解码。 |
| 明确开始 AI、运行配方 | 固定此次输入版本和参考图。优先复用匹配的已保存产物，缺少时再按所需尺寸渲染。勾选的步骤进入工作流，耗时操作显示进度。 |
| 生成完成、切看其他照片 | 新产物写入原任务的照片和步骤。迟到结果不会顶替正在查看的另一张照片。 |
| 导出或保存正式版本 | 按指定分辨率、格式和版本生成实际文件。界面区分「工程已写入」「正在导出」「成片已导出」。 |

## 迁入正式版

- **先接人物与调色。** 让两种编辑器读同一个照片会话、一个视口和一条可分支的历史。将现有本机像素引擎接到同一个预览调度器。分离轻量工程自动保存与全尺寸渲染，保留 RAW 原片及母版。
- **再接图层、照片项目与 AI。** 图层返回编辑参数和预览结果。仅在确实需要图片资产时生成完整结果。沿用现有的工作流、素材、步骤和尝试编号，以及账号绑定、并发限制、失败恢复和批量检查点。
- **最后迁移入口。** Windows、网页和安卓使用相同的菜单层级。旧作品链接解析到同一画布上的准确版本。账号登录可使用系统浏览器，返回后恢复原文档。全部既有工具、格式与恢复路径验证通过后，再切换正式版默认入口。

## 本次能试到的内容

单文件内可实际调色、画中性灰和高低频笔触、框选局部调色范围、添加文字图层，以及跨工具撤销、历史分支、同步选中照片的整体调色和导出成片。搜索与逐级菜单操作同一套工具入口。AI 区演练输入快照、画幅设置、步骤中断和恢复，不消费生成额度。原型编辑记录只保留在当前窗口，关闭前可导出图片。后台工程持久化、全套图层编辑、真实 AI 请求和旧工程迁移属于正式版接入范围。

验收以可观察的动作为准。带着曝光调整、局部范围和放大位置依次打开人物、图层、AI、步骤和调色，应保持同一个画布元素、视口、选区、照片与历史位置。期间页面导航、图片重新解码、PNG/JPEG 编码、像素计算任务及网络请求均为零。另查首次导入、未完成输入、原图对比、批量同步、历史分支与原尺寸导出。手机在 320 和 390 像素宽度下应能一边看图一边调参数。

### 已通过的原型实测

- 在同一份已调曝光、已框选和已放大的照片上切换五个面板。浏览器记录到 0 次页面导航、0 次重新解码、0 次图片编码、0 次像素任务和 0 次网络请求。切换前后的画布元素、照片、历史位置、选区、缩放与平移一致。
- 实际导入测试图片并导出 PNG。原图对比中的导出使用成片，显式选中历史快照后的导出与该快照像素一致。滑动对比两侧抽样和分别查看原图、成片时的位置一致。
- 320 × 568 和 390 × 844 视口没有整页横向或纵向溢出。Chromium 触屏模拟完成双指缩放、人物落笔、工具切换、搜索灯架、未松手参数的保留和撤销。实体 iPhone、Android 与正式工程的自动保存、真实模型生成需要在正式接入后验证。
